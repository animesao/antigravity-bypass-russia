## What's Changed

- Добавлена полная поддержка **Linux** (Ubuntu, Debian, Fedora, Arch Linux и др.) на архитектурах x86_64 и ARM64.
- Интеграция со службой **Systemd** (`antigravity-bypass-russia.service`) для автономной фоновой работы локального DNS-релея.
- Селективная маршрутизация доменов Google AI через `/etc/hosts` и очистка DNS-кэша через `resolvectl flush-caches`.
- Автоматическое определение основного сетевого интерфейса и шлюза по умолчанию (`ip route`).
- Поддержка безопасной эскалации прав через `sudo` и `pkexec` (PolicyKit) с сохранением пользовательского контекста.
- Автоматическое закрытие и обработка блокировок файлов процессов `antigravity`, `antigravity-ide` и `agy`.
- Автоматическая сборка готовых релизных исполняемых файлов для Linux (`antigravity-bypass-russia-linux-x64`).

**Full Changelog**: https://github.com/animesao/antigravity-bypass-russia/compare/v2.4.0...v2.5.0
