## What's Changed

- **Универсальный скрипт установки в один клик** (`scripts/install.sh`):
  Установка одной командой на Linux и macOS:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/animesao/antigravity-bypass-russia/main/scripts/install.sh | bash
  ```
- **Сборка для Linux ARM64** (`aarch64-unknown-linux-gnu`):
  Добавлена поддержка Linux на архитектуре ARM64 (Raspberry Pi, ARM-серверы, Asahi Linux) с автоматической компиляцией в релизах.
- **Готовые пакеты `.deb`** (`antigravity-bypass-russia-linux-x64.deb`):
  Для удобной системной установки в Ubuntu, Debian, Linux Mint и производных дистрибутивах.
- **Поддержка Arch Linux / Manjaro**:
  Добавлена спецификация `PKGBUILD` для лёгкой установки и упаковки в Arch Linux.
- **Симлинк и псевдоним `ag-bypass`**:
  Для быстрого и удобного запуска из любого терминала.

**Full Changelog**: https://github.com/animesao/antigravity-bypass-russia/compare/v2.5.0...v2.6.0
